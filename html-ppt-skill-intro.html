⚡ html-ppt skill · HTML 演示文稿生成工具

把 PPT 变成
可交互的 HTML 页面

html-ppt skill 是一个面向幻灯片、演讲稿、分享页、小红书图文的模板化 HTML 演示工具。它强调主题、布局、动画、演讲者模式和键盘导航，让内容既能展示，也能讲。

36主题风格，覆盖商务、技术、小红书、学术等场景
31布局模板，可直接拼装出完整页面
20+Canvas FX 动效，适合做氛围感和转场

它适合做什么

演讲 / 技术分享

适合做带逐字稿的演讲型 deck，尤其适合需要 presenter mode 的场景。

产品发布 / 商务汇报

用 pitch-deck、corporate-clean、swiss-grid 等风格快速搭出正式展示页。

小红书图文 / 长页内容

可以做成单页长图风格页面，适合内容传播、教程和分享稿。

核心能力

1
主题系统

一套 token 驱动的设计语言，切换主题不用重写结构。

2
布局库

直接复用现成布局，少写 CSS，多拼内容。

3
动画与特效

支持 CSS 动画和 canvas 特效，做出更有表现力的页面。

4
演讲者模式

可查看当前页、下一页、逐字稿和计时器，适合正式演示。

怎么用

npx skills add https://github.com/lewislulu/html-ppt-skill

# 然后按模板创建 deck
./scripts/new-deck.sh my-talk
open examples/my-talk/index.html

一句话总结

如果你想要的不只是“能显示的 PPT”，而是“能讲、能看、能切换风格、还能做成网页”的内容，html-ppt skill 就是干这个的。
